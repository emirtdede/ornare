# Asset policy

Only original Ornare/Vellium assets or explicitly compatible open-source assets may be stored here.

Forbidden:

- Apple Design Resources;
- SF Symbols exports;
- Apple/macOS UI kit assets;
- SF Pro font files;
- copied competitor icons;
- unverified GitHub images/templates.

Standard action icons should preferably come from Microsoft Fluent System Icons with license notices recorded. Signature actions should use original SVG artwork.
