# Third-Party Notices

This file is a template. Release builds must replace it with a generated/reviewed inventory containing every shipped direct/transitive component and every copied OSS source fragment requiring notice.

For each entry record:

- name;
- version/commit;
- upstream URL;
- license;
- copyright notice;
- modifications/source reuse notes;
- shipped binary/source/asset role.

Never assume NuGet package metadata alone covers native transitive assets.
