## 3. Store Listing Descriptions

### 3.1 Short Summary (for Search & Browse Cards)
Personalize your Windows 11 folders instantly. Right-click any local folder, pick or paste an image, and enjoy beautiful, durable icons with zero telemetry and full privacy.

### 3.2 Full Description (Store Product Detail Page)

```text
Ornare is a modern, native Windows 11 utility designed to make folder customization effortless, elegant, and durable.

RIGHT-CLICK TO PERSONALIZE
Transform the look of your desktop and workspace in seconds:
• Right-click any local folder in File Explorer.
• Select "Set Folder Icon" to summon the lightweight Quick Panel.
• Drop, choose, or paste any image — PNG, JPEG, WebP, BMP, GIF, or ICO.
• Your high-resolution folder icon is generated and applied instantly.

DESIGNED EXCLUSIVELY FOR WINDOWS 11
Built with native WinUI 3 and Windows App SDK, Ornare integrates seamlessly with the Windows 11 aesthetic:
• Fluent Design styling with subtle mica materials and smooth animations.
• Full support for system Dark, Light, and High Contrast themes.
• Native English and Turkish localization right out of the box.
• Compact, lightning-fast Explorer context menu integration.

RESPECTS YOUR SYSTEM AND FILES
Unlike traditional tools that alter global system files or run heavy background services:
• Safe & Non-Destructive: Never modifies system folders or unrelated desktop.ini entries.
• Fully Reversible: Undo previous icon assignments or Reset to default folder icons with a single click.
• Offline & Private: Zero telemetry, zero accounts, no cloud dependencies, and zero analytics. Your images and folders remain strictly on your device.
• True Durability: Customizations persist through Windows restarts and app uninstallation without requiring Ornare to stay open in the background.

MANAGEMENT & HEALTH AT A GLANCE
Launch the full Ornare Manager anytime to:
• Browse your Library of saved icons and curated color sets.
• Review Recent assignments and pin your Favorites.
• Check folder health and restore broken or renamed folder links with automated Repair.

SYSTEM REQUIREMENTS:
• Windows 11 Version 24H2 / 25H2 (Build 26100+)
• Architecture: Windows 11 x64
```

## 4. Key Features List (Bullet Points)

1. **Instant Context Menu Access:** Right-click any folder to open the minimalist Quick Panel.
2. **Universal Image Support:** Drag and drop PNG, JPEG, WebP, BMP, GIF, or ICO files.
3. **Clipboard Integration:** Paste images directly from your clipboard with Ctrl+V.
4. **Offline & Private by Design:** No accounts, no data collection, no telemetry, and no cloud uploads.
5. **Durable & Reversible:** Customizations stay intact across reboots; easily Undo or Reset whenever desired.
6. **Native WinUI 3 Performance:** Fluid, responsive, and adheres to Windows 11 design standards.
7. **Full Dual-Language Support:** First-class English and Turkish interfaces.
8. **Curated Library & History:** Easily reuse favorite icons and track customized folders.
