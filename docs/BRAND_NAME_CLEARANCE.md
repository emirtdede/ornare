# Brand Name Clearance — Ornare

## Current use

`Ornare` is selected as the project/product working name because Latin *ornare* means “to adorn / decorate,” matching the product's purpose.

## Important legal status

This research is not legal clearance. ORNARE is already used/registered in multiple non-software commercial classes and jurisdictions (for example furniture/retail and cosmetics records exist). That does not automatically prohibit software use, but it means the name must not be treated as legally cleared.

## Release gate

Before public branding, Store reservation or paid launch:

1. search Microsoft Store;
2. search major software/app directories;
3. search GitHub/package ecosystems;
4. check relevant domains/social handles;
5. perform EUIPO/TÜRKPATENT/WIPO/USPTO or counsel-led trademark search for relevant software classes, especially Nice Class 9 and applicable SaaS/service classes;
6. assess likelihood of confusion with existing ORNARE brands;
7. reserve the Store name/domain only after acceptance.

Architecture namespaces must not depend so strongly on public branding that a rename becomes expensive.
