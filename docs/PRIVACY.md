# Ornare Privacy Statement

**Effective Date:** 2026-09-25  
**Version:** 1.0 (Release Candidate)

Ornare is built on a non-negotiable principle: **your files, images, and folder customizations belong strictly to you and remain entirely on your local machine.**

---

## 1. Zero Network Transmission

- **No Remote Servers**: Ornare does not operate or communicate with any cloud server, web API, remote database, or content delivery network.
- **No Network Capabilities**: The packaged MSIX application does not declare the `internetClient` or any networking capability in its application manifest. Outbound network sockets cannot be opened by the application runtime.
- **Zero Uploads**: Your source images, generated `.ico` files, folder names, and file paths are never uploaded, transmitted, or synchronized over any network.

---

## 2. Zero Telemetry & Analytics

- Ornare contains **no telemetry libraries**, no analytics trackers, no usage tracking, no performance reporting beacons, and no crash report uploaders.
- No user identifiers, device identifiers, IP addresses, or session metrics are collected or shared.

---

## 3. Zero Accounts or Login

- Ornare does not require or support user accounts, registration, login credentials, emails, or personal identification.

---

## 4. Local Storage and Data Boundaries

- All application metadata (recent items, library asset hashes, favorite selections, folder assignment records) is stored strictly in a local SQLite database located in your local application directory (`AppData\Local\Packages\Ornare_...\LocalState\ornare.db` or `%LOCALAPPDATA%\Ornare\ornare.db`).
- This database is local-only, never leaves your computer, and is never shared with third parties.

---

## 5. Diagnostic Export & Path Anonymization

- Any diagnostic report generated by Ornare is strictly **user-initiated** via the **Export Diagnostic Report** button in Settings.
- When generated:
  - Personal user profile paths (such as `C:\Users\username\...` or `/home/username/...`) are automatically sanitized and replaced with `<REDACTED_USER>`.
  - The report contains only aggregate counts (e.g. total customized folders, theme preference, OS build) and redacted error strings.
  - Image binary bytes, thumbnails, and personal file contents are never included in diagnostic exports.
  - The resulting JSON file is saved locally to your selected disk location. It is never automatically transmitted.

---

## 6. Contact and Inquiries

For technical questions or privacy inquiries regarding Ornare, refer to the project repository's official private communication channels.
