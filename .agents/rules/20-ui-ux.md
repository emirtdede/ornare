# UI/UX Rules

- Premium, quiet, minimalist, precise.
- Apple HIG is a principle reference only; Windows semantics/controls/accessibility remain native.
- Never ship Apple Design Resources, SF Symbols, SF Pro, copied macOS assets or pixel-identical Apple UI.
- Absolutely no card-inside-card / panel-inside-panel dashboard composition.
- Do not box every group. Use whitespace, alignment, hierarchy, dividers and semantic state.
- Accent color is sparse. Glass/material is sparse. Shadows are sparse.
- No aurora/neon/animated gradient blobs/particles/3D tilt/confetti/cursor-follow effects.
- No emoji UI icons.
- Quick panel has one dominant action and no Apply button.
- Default image layout is non-destructive contain.
- Motion must be short, purposeful and compositor-friendly; respect reduced motion.
- UI changes require Light/Dark screenshots, Turkish check, DPI check and UIA/keyboard check.
- If a screen resembles a generic SaaS dashboard, redesign it.
