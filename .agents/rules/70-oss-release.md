# OSS & Release

- Never copy code/assets without explicit license/provenance.
- Record copied OSS source at commit/file level and preserve required notices.
- Apple Design Resources are prohibited.
- qmatteoq ContextMenuSample is reference-only unless a compatible license is later verified.
- Keep dependency count low; every package needs a reason.
- Stable dependencies only unless an ADR approves preview use.
- Release requires vulnerability audit, license inventory, WACK, install/update/uninstall and acceptance gates.
- Public release requires final Ornare naming/trademark/Store clearance.
