# Agent Execution

For substantial work:

1. inspect relevant specs and source;
2. state the concrete implementation objective/risk list internally or in task notes;
3. query Microsoft Learn MCP for version-sensitive Windows facts;
4. implement the smallest complete slice;
5. build/test;
6. run UI/perf/security checks relevant to change;
7. compare against acceptance criteria;
8. report evidence and remaining risks.

Do not stop after creating a plan when implementation was requested. Do not mark tasks complete based on visual intuition or unrun tests. Do not rewrite unrelated code “for consistency.”
