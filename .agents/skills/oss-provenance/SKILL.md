# OSS Provenance Skill

For each candidate:

1. verify upstream owner/repository;
2. verify explicit license at the exact commit/file;
3. inspect bundled third-party assets/code;
4. capture version/commit/source path;
5. assess maintenance/security/package size;
6. copy only the necessary parts;
7. preserve notices;
8. add/update tests and `THIRD-PARTY-NOTICES` inventory.

Never use Apple Design Resources or unlicensed GitHub samples in product source.
