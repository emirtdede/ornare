# Packaging & Release Skill

- Stable Windows App SDK only.
- x64 + ARM64 package assets/COM registration.
- Store primary distribution.
- No dev/self-signed cert in public release.
- Test clean install, update, repair/reinstall, uninstall keep-customizations.
- Run WACK.
- Include third-party notices and privacy statement.
- Do not ship while name-clearance gate is open.
